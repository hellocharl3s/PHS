Spotting patterns in a growing square diagram

▼

🤔 Think About It First!

Before looking at the answer, ask yourself:

  • In Figure 1, the large square has side = 2. How many small squares fit inside? (2 × 2 = ?)
  • In Figure 2, the side = 3. Total = 3 × 3 = ?
  • What is the side length for Figure n?
  • Look at the grey squares: 1, 4, … Do you recognise these numbers?
  • White = Total − Grey. Can you write a formula?
✅ Solution

The side of the large square in Figure n = n + 1.
2
Total squares = (n+1)²  (area of a square)
3
Grey squares: 1, 4, 9, 16, … — these are perfect squares → Grey = n²
4
White = Total − Grey = (n+1)² − n² = 2n + 1

Part (ii)
A large square has a side of 65 units. How many white unit squares does it have?
🤔 Think About It First!

If side = n + 1 = 65, what is n?

Once you know n, which formula gives the number of white squares?

✅ Solution
1

2
White = 2n + 1 = 2(64) + 1 = 128 + 1 = 129

Part (iii)
Will there be a figure with exactly 920 grey unit squares? Explain your answer.
🤔 Think About It First!

Grey squares = n². So we need n² = 920.

Is there a whole number n that satisfies this? Try squaring some numbers close to 30…

  • 30² = ?
  • 31² = ?
  • Is 920 between these two? What does that tell you?
✅ Solution
1
We need n² = 920, so n = √920 ≈ 30.33
2
30² = 900 and 31² = 961. So 920 falls between them — it is not a perfect square.
3
Since n must be a whole number, there is no such figure.
⭐No. Grey squares are always perfect squares (n²), and 920 is not a perfect square, so no such figure exists.

Part (iii)
As the figure number increases, how does the number of dots change?
🤔 Think About It First!

Look at the differences between consecutive terms: 6−3=3, 10−6=4, 15−10=5…

Is the difference constant (same each time)? Or does it change?

✅ Solution

Part (iv)
Belle says the formula is n² + 3n + 2. Do you agree?
🤔 Think About It First!

The easiest way to check a formula: test it with a value you already know!

  • When n = 1, there are 3 dots.
  • Plug n = 1 into Belle's formula: 1² + 3(1) + 2 = ?
  • Does it match? If not, find the correct formula.
✅ Solution
1
Test n = 1:   1² + 3(1) + 2 = 6, but the answer should be 3. ✗
2
Belle is wrong. The correct formula is: \(\dfrac{(n+1)(n+2)}{2}\)
3
Verify: n=1 → (2×3)/2 = 3 ✓  |  n=2 → (3×4)/2 = 6 ✓  |  n=3 → (4×5)/2 = 10 ✓
⚠️Always verify your formula with at least 2–3 known values before accepting it!

Sequence Tn

Finding a general term from a pattern

▼
📋Given:   T₁ = 1² + 4 = 5  |  T₂ = 2² + 8 = 12  |  T₃ = 3² + 12 = 21
Part (i)
Find T₄.
🤔 Think About It First!

Look carefully at the pattern:

  • T₁ = 1² + 4 = 1² + 4×1
  • T₂ = 2² + 8 = 2² + 4×2
  • T₃ = 3² + 12 = 3² + 4×3
  • So T₄ = 4² + 4×? = ?
✅ Solution
\(T_4 = 4^2 + 4(4) = 16 + 16 = 32\)
⭐T₄ = 32
Part (ii)
Find an expression for Tn in terms of n.
🤔 Think About It First!

Every term follows the same structure. What stays the same, and what changes as n increases?

✅ Solution
⭐\(T_n = n^2 + 4n\)
Part (iii)
Evaluate T₅₀.
🤔 Think About It First!

Now that you have the formula T_n = n² + 4n, simply substitute n = 50. Be careful with your arithmetic!

✅ Solution
\(T_{50} = 50^2 + 4(50) = 2500 + 200 = 2700\)
⭐T₅₀ = 2700

Fraction Pattern

Spotting structure in fraction sums

▼
📋
The pattern:
\(\dfrac{1}{2}+\dfrac{1}{3} = \dfrac{3+2}{2\times3} = \dfrac{5}{6}\)
\(\dfrac{1}{3}+\dfrac{1}{4} = \dfrac{4+3}{3\times4} = \dfrac{7}{12}\)
\(\dfrac{1}{4}+\dfrac{1}{5} = \dfrac{5+4}{4\times5} = \dfrac{9}{20}\)
\(\dfrac{1}{5}+\dfrac{1}{6} = \dfrac{6+5}{5\times6} = \dfrac{11}{30}\)
Part (i)
Write down the 5th line in the pattern.
🤔 Think About It First!

Look at the denominators in each line: (2,3), (3,4), (4,5), (5,6)…

What pair of denominators will appear in line 5?

What will the numerator and denominator of the answer be?

✅ Solution
\(\dfrac{1}{6}+\dfrac{1}{7} = \dfrac{7+6}{6\times7} = \dfrac{13}{42}\)
⭐5th line: \(\dfrac{1}{6}+\dfrac{1}{7} = \dfrac{13}{42}\)
Part (ii)
Given: \(\dfrac{1}{k}+\dfrac{1}{21} = \dfrac{21+k}{k\times21} = \dfrac{p}{q}\). Find k, p and q.
🤔 Think About It First!

In every line, the two denominators are consecutive integers (they differ by 1).

  • The second fraction has denominator 21.
  • What must the first fraction's denominator (k) be?
  • Once you know k, finding p and q is straightforward!
✅ Solution
1
Denominators are consecutive: k and k+1 = 21, so k = 20
2
\(\dfrac{1}{20}+\dfrac{1}{21} = \dfrac{21+20}{20\times21} = \dfrac{41}{420}\)
⭐k = 20,   p = 41,   q = 420
Part (iii)
Find the value of \(\dfrac{5}{80}+\dfrac{5}{81}\).
🤔 Think About It First!

This does not look exactly like the pattern, but can you rearrange it to use the pattern?

  • Notice both fractions have a 5 on top. Can you factor it out?
  • After factoring, what does it become? Does that match any line of the pattern?
✅ Solution
1
Factor out 5: \(\quad\dfrac{5}{80}+\dfrac{5}{81} = 5\!\left(\dfrac{1}{80}+\dfrac{1}{81}\right)\)
2
Use the pattern: \(\quad\dfrac{1}{80}+\dfrac{1}{81} = \dfrac{81+80}{80\times81} = \dfrac{161}{6480}\)
3
\(5 \times \dfrac{161}{6480} = \dfrac{805}{6480} = \dfrac{161}{1296}\)
⭐\(\dfrac{5}{80}+\dfrac{5}{81} = \dfrac{161}{1296}\)

Cube Sum Pattern

Sum of cubes equals a perfect square

▼
📋
\(1 = 1^2 = 1^3\)
\(9 = 3^2 = 1^3+2^3\)
\(36 = 6^2 = 1^3+2^3+3^3\)
⋮
\(3025 = a^2 = 1^3+2^3+3^3+\cdots+b^3\)
Part (i)
Write down the 4th line in the pattern.
🤔 Think About It First!

The left column: 1, 3, 6, … These are triangular numbers! (1, 1+2, 1+2+3, …)

  • What is the 4th triangular number? (1+2+3+4 = ?)
  • Square it to get the left side.
  • The right side is the sum of cubes up to the 4th cube.
✅ Solution
1
4th triangular number = 1+2+3+4 = 10, and 10² = 100
2
Check: 1³+2³+3³+4³ = 1+8+27+64 = 100 ✓
⭐\(100 = 10^2 = 1^3+2^3+3^3+4^3\)
Part (ii)
Find the value of a and of b.
🤔 Think About It First!

Finding a: We know 3025 = a². What operation do you do to both sides to find a?

Finding b: The pattern shows a = 1+2+3+…+b. We know a, so we need to find which value of b gives that sum.

  • The sum formula is: \(\dfrac{b(b+1)}{2} = a\)
  • Substitute a and solve for b. Try b = 10.
✅ Solution
1
Find a: \(\quad a = \sqrt{3025} = 55\)
2
Find b: \(\quad\dfrac{b(b+1)}{2} = 55 \Rightarrow b(b+1) = 110\)
3
Try b = 10:   10 × 11 = 110 ✓
⭐a = 55,   b = 10

Multiplication Pattern

n × (n + 4) sequence

▼
📋
\(5 = 1\times5 = 1\times(1+4)\)
\(12 = 2\times6 = 2\times(2+4)\)
\(21 = 3\times7 = 3\times(3+4)\)
\(32 = 4\times8 = 4\times(4+4)\)
⋮
\(396 = a\times b = a\times(a+4)\)
Part (i)
Write down the 5th line in the pattern.
🤔 Think About It First!

The pattern for line n is: n × (n + 4).

For line 5, substitute n = 5. What do you get?

✅ Solution
⭐\(45 = 5\times9 = 5\times(5+4)\)
Part (ii)
Find the values of a and b.
🤔 Think About It First!

We know a × (a + 4) = 396. Expand the brackets: a² + 4a = 396.

  • Rearrange to form a quadratic equation: a² + 4a − 396 = 0
  • Can you factorise it? Look for two numbers that multiply to −396 and add to +4.
  • Try: 18 and −22. Check: 18 × (−22) = −396 ✓ and 18 + (−22) = −4 ✗
  • Try: −18 and 22. Check: (−18) × 22 = −396 ✓ and −18 + 22 = 4 ✓
  • So the factorisation is (a − 18)(a + 22) = 0
✅ Solution
1
Set up: \(\quad a(a+4) = 396 \Rightarrow a^2+4a-396=0\)
2
Factorise: \(\quad(a-18)(a+22)=0\)
3
a = 18 (taking the positive value),   b = 18 + 4 = 22
4
Check: 18 × 22 = 396 ✓
⭐a = 18,   b = 22
Part (iii)
Write down the 20th line in the pattern.
🤔 Think About It First!

Use the formula: line n gives n × (n+4).

Substitute n = 20.

✅ Solution
⭐\(480 = 20\times24 = 20\times(20+4)\)
Part (iv)
Will there be a line with 2204 on the left-hand side? Explain your answer.
🤔 Think About It First!

For 2204 to appear, we need n(n+4) = 2204, where n is a whole number.

  • Try nearby values: what does n = 45 give? What about n = 46?
  • Is 2204 ever hit exactly?
  • Alternatively, rearrange: n² + 4n − 2204 = 0. Complete the square to check if n is a whole number.
✅ Solution
1
We need n(n+4) = 2204. Rearrange: n² + 4n − 2204 = 0
2
Complete the square: (n+2)² = 2208
3
Check: 47² = 2209 and 46² = 2116. So 2208 is not a perfect square, meaning n is not a whole number.
4
Checking nearby: n=45 gives 45×49 = 2205 (one too many). 2204 is skipped entirely.
⭐No. 2204 will not appear. Since n must be a whole number, and n(n+4) = 2204 has no whole-number solution, no such line exists.
